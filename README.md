## Notes — Classic Rust

Pure Rust: no frameworks, no extensions. See [`obsidian_notes/Classic_Rust/`](obsidian_notes/Classic_Rust/).

1. **Hello World** — environment setup, anatomy of a Rust program, Hello Cargo
2. **Programming a Guessing Game** — variables, user input, `Result`, `println!` placeholders, random numbers, loops
3. **Common Programming Concepts** — mutability, data types, functions, comments, control flow
4. **Understanding Ownership** — ownership, references & borrowing, the slice type
5. **Using Structs to Structure Related Data** — defining and instantiating structs *(in progress)*
