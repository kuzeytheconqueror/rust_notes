## Introduction
So the basic hello world at rust is:

```
fn main() {
println!("Hello World!");
}
```

It feels like between Java and C++ but not sure. We will be studying C++ in depth either so no worries.

## Running the file

So to run the Rust, you need to use the rust compiler. Similar to 'GCC' but rust edition:
```
$ rustc main.rs
$ ./main
Hello, world!
```
